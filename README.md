# Shashlyk Booking Telegram Bot

Телеграм-бот на Python для бронирования зоны для шашлыка в жилом комплексе. Бот показывает доступные слоты на ближайшие дни и позволяет пользователям закреплять за собой удобное время.

## Возможности

- просмотр свободных слотов на ближайшие 7 дней;
- бронирование времени с помощью удобного меню с кнопками;
- просмотр списка своих бронирований и отмена при необходимости;
- хранение данных в JSON-файле.

## Требования

- Python 3.10+
- Telegram Bot Token (переменная окружения `TELEGRAM_TOKEN`)
- Возможность устанавливать дополнительные зависимости из PyPI (используется 
  пакет `python-telegram-bot` с extra `rate-limiter`)

## Установка и запуск

1. Создайте и активируйте виртуальное окружение.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Установите токен телеграм-бота:
   ```bash
   export TELEGRAM_TOKEN="ваш токен"
   ```
4. Запустите бота:
   ```bash
   python -m bot.main
   ```

По умолчанию брони сохраняются в файле `data/bookings.json`. Путь можно изменить переменной окружения `BOOKING_DATA_FILE`.

## Структура проекта

- `bot/storage.py` — логика хранения и модели данных.
- `bot/bot.py` — настройка телеграм-бота и обработчики команд.
- `bot/main.py` — точка входа для запуска.

## Настройка расписания

По умолчанию бот предлагает слоты каждые 2 часа с 10:00 до 22:00. Эти параметры можно изменить при генерации слотов в модуле `storage.py`.
